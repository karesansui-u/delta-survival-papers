# Scope And Silence Catalog

Status: boundary memo. Not evidence. Not a freeze document. Not a retreat.

Date: 2026-04-27

Upstream source:

- `analysis/falsification_and_rival_frameworks.md` (especially F3)

Purpose:

List the kinds of systems where the structural persistence / structural
balance-principle language should stay silent unless additional structure is fixed in
advance. The goal is to prevent the program from drifting into:

```text
"everything dynamic is secretly a scalar loss / repair balance"
```

That drift would make the program weaker, not stronger.

## 1. Governing Rule

The language is allowed to speak only after the maintained structure is fixed.

At minimum, the program needs a pre-fixed answer to:

1. what structure is being maintained;
2. what counts as loss;
3. what counts as recovery;
4. what the time index is;
5. what outcome or boundary is being predicted.

If those are not fixed, silence is healthier than forced translation.

## 2. Catalog

| System family | Why the theory should be silent by default | What extra structure would be needed |
|---|---|---|
| Critical phase transitions | The main object is often singular behavior, symmetry breaking, or critical exponents, not monotone loss / repair balance | A concrete order parameter, maintained phase, and measure fixed before interpretation |
| Hopf bifurcation / limit cycles | Net action may oscillate while the real object is a stable cycle, not collapse or maintenance of a scalar load | A pre-fixed cycle basin or amplitude-based maintained structure |
| Self-organized criticality / heavy-tail avalanche systems | Mean drift can be misleading; tail structure matters more than average one-step balance | Tail / large-deviation layer and explicit rare-event target |
| Static complexity-class statements | There may be no natural time-indexed \(Z_t\), \(b_t\), or \(B_n\) at all | An exposure or reduction path with a genuine sequential index |
| Multi-attractor systems without a chosen target basin | "Maintenance" is undefined until one basin or attractor is privileged | Target basin / structure declared before analysis |
| Objective-switching or regime-switching systems | Loss and repair semantics change with the objective, making one scalar balance ambiguous | Piecewise target definition with explicit regime segmentation |

## 3. What Silence Means

Silence does not mean the theory is false in those domains.

It means:

```text
the current structural-persistence balance vocabulary is under-specified there
```

That is a healthy outcome, because it keeps the program falsifiable. The bad
failure mode would be to force a translation after seeing the answer and then
claim success.

## 4. Interaction With Current Anchors

The current anchors are relatively safe because they do pre-fix the maintained
structure:

- Route A fixes a feasibility / survival quantity before testing coordinates;
- queueing fixes queue load / excess demand;
- repair-maintenance fixes damage, repair, and margin;
- Backblaze fixes future drive failure under a loss-only observational design;
- Route C fixes scoped task structure and then measures outcome under that
  fixed structure.

This catalog therefore does not weaken the current validated anchors. It
clarifies why those anchors are acceptable and why more ambitious "everything"
claims are not yet justified.

## 5. Use Rule For Future Anchors

Before opening a new anchor, ask:

1. Is the maintained structure explicit?
2. Is loss defined without looking at the outcome?
3. Is recovery defined without looking at the outcome?
4. Is the target event or regime fixed before analysis?
5. If not, should the program stay silent here?

If the answer to (5) is yes, that is not failure. It is a scope boundary.

## 6. Non-Claims

This memo does not claim:

1. the listed system families can never be brought into the program;
2. silence is a defeat of the core theory;
3. current anchors are enough to cover all dynamic structure;
4. rival frameworks are unnecessary.

It claims only:

```text
scope boundaries are part of the program's scientific discipline. A language
that cannot say where it should stay silent is not stronger; it is less
falsifiable.
```
