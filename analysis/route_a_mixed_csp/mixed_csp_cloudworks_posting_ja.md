# CloudWorks 募集文案（Mixed-CSP 外部再現実行）

状態: CloudWorks に掲載するための日本語募集文案。これは研究内容の解説文
ではなく、外部実行者に作業内容を分かりやすく伝えるための実務文書である。

日付: 2026-04-27

## 1. 依頼タイトル候補

第一候補:

```text
【Python実行のみ】研究用パッケージの再現実行（zip可・改善不要）
```

代替候補:

```text
【開発不要】Pythonパッケージの再現実行と結果返送
```

```text
【CLI作業】凍結済みPythonパッケージの外部再実行
```

```text
【Python】指定手順どおりの再現実行・結果レポート
```

一番おすすめなのは第一候補です。  
理由:

- `Mixed-CSP` を前面に出さない
- `開発` ではなく `実行` だと伝わる
- `zip可` を入れると応募の心理的障壁が下がる
- `改善不要` を入れると仕事の範囲が伝わる

## 2. そのまま使える募集文

```text
【 概要 】
公開済みの Python 実行パッケージを、指定手順どおりに外部環境で再実行し、
結果を返送していただくお仕事です。

新機能開発や改善提案ではなく、再現実行タスクです。

【 依頼内容 】
・作業内容：
  指定した公開コミット、またはそのコミットから作成した zip 一式を受け取り、
  手順書どおりに再実行して結果を返送してください。

・依頼工程：
  1. ファイル受け取り（git または zip）
  2. Python 依存関係の導入
  3. 事前確認の実行
  4. 診断コマンドの実行
  5. 本実行
  6. 結果集計
  7. 結果返送

・やってほしいこと：
  - 手順書どおりに実行する
  - 出力を指定ディレクトリに保存する
  - 結果ファイル、ハッシュ、行数、簡単な実行メモを返送する

・やらなくてよいこと：
  - 改善提案
  - コード修正
  - 評価指標の変更
  - 設計変更
  - 新機能開発

・使用言語：
  Python

・実行形式：
  コマンドライン実行

【 用意してあるもの 】
・仕様書：
  手順書あり

・実行用ファイル：
  あり（git で渡すか、zip 一式で渡します）

・必要資料：
  あり（実行手順書、確認用ファイル、返送項目一覧を用意しています）

【 納期 】
相談して決めたい

【 所要時間の目安 】
2〜5時間程度を想定
（環境構築状況によって前後して構いません）

【 契約金額(税抜) 】
5,000円〜15,000円程度でご相談
まずは見積もりをご提示ください

【 重視する点・経験 】
・Python 実行環境があること
・requirements.txt から依存関係を導入できること
・コマンドラインで Python スクリプトを実行できること
・手順書どおりに作業し、結果を返送できること

※ Git の利用は必須ではありません。zip での受け取りでも大丈夫です。
※ LLM の利用も必須ではありません。使える場合は手順整理に使って構いませんが、
  設計変更や改善提案は不要です。

【 応募方法 】
応募時に、次の内容を簡単に教えてください。
1. Python の実行環境があるか
2. requirements.txt から依存関係を入れられるか
3. git / zip のどちらで受け取りたいか
4. コマンドラインで Python スクリプトを実行した経験があるか
5. 想定作業時間と希望金額

ご質問がありましたら気軽にご連絡ください。
応募をお待ちしています。
```

## 3. 応募者に最初に確認したいこと

CloudWorks 上で最初に見るポイントはこれで十分です。

1. Python 実行環境があるか
2. `requirements.txt` から依存関係を入れられるか
3. CLI 実行に抵抗がないか
4. zip 受け取りで問題ないか
5. 「改善」ではなく「手順どおりの再現実行」だと理解しているか

## 4. 応募者への初回返信テンプレート

```text
ご応募ありがとうございます。

今回お願いしたいのは、開発や改善ではなく、
凍結済みの Python パッケージを手順どおりに再実行して、
結果を返送していただく作業です。

もし可能でしたら、以下を教えてください。

1. Python 実行環境の有無
2. requirements.txt から依存関係を入れられるか
3. git と zip のどちらで受け取りたいか
4. コマンドラインで Python スクリプトを実行した経験の有無
5. 想定作業時間とお見積もり

条件が合いそうであれば、次に実行手順書とファイル一式をお送りします。
よろしくお願いします。
```

## 5. 採用後に送る一言

```text

指定手順どおりに実行し、出力ハッシュ・行数・結果要約・実行環境メモを
返送してください。
```

```text

「Python パッケージの再現実行作業」として募集するのが一番通りやすい。
```
