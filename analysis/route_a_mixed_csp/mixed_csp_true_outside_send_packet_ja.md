# Python 再現実行のお願い（Mixed-CSP 実行パッケージ）

状態: 外部の実行者にそのまま渡すための日本語パック。これは新しい実験計
画ではなく、すでに凍結済みの Mixed-CSP 本実行パッケージを外部環境で再
実行してもらうための説明文である。

日付: 2026-04-27

## 1. この依頼の要点

この依頼でお願いしたいのは、理論の評価でも改善提案でもなく、

```text
公開済みリポジトリの指定コミットから凍結済みパッケージをそのまま再実行
し、同じ質的支持判定が再現するかを確認すること
```

だけです。

言い換えると、

- 研究内容への賛否はこの段階では不要
- 予測子や評価指標の変更は不要
- 新しい実験設計や調整も不要
- 必要なのは「指定手順どおりに回して、結果を返すこと」
- Git を使う方法でも、送られた zip を展開して実行する方法でもよい

です。

## 2. まず最初に読んでほしい 30 秒版

あなたにお願いしたいことは、次の 5 点です。

1. 指定された公開コミットからリポジトリを複製する
   または、そのコミットから作られた zip を展開する
2. `requirements.txt` から依存関係を入れる
3. 正式参照ファイルは上書きせず、別出力先で再実行する
4. 事前確認 / 診断 / 本実行 / 結果集計を順番に実行する
5. 出力ハッシュ・行数・支持フラグ・要約・環境メモを返す

もしこれが可能なら、この依頼の本質は理解できています。

この依頼に向いているのは、次の条件を満たす人です。

1. Python 実行環境がある
2. `requirements.txt` から依存関係を入れられる
3. zip 展開または git のどちらかでファイルを受け取れる
4. 手順書どおりに実行して、結果ファイルを返せる

LLM の利用は **必須ではありません**。使えるなら手順整理に役立ちますが、
なくても実行できます。

## 3. この依頼で「してほしいこと」

してほしいことは、次の通りです。

1. 指定したコミットの状態を複製する
   または、そのコミットから作られた zip を展開する
2. パッケージに書かれた凍結済み設計を変えずに実行する
3. 出力は `external_outputs` のような別ディレクトリに出す
4. 正式参照用の JSONL / JSON / 要約ファイルは上書きしない
5. 実行後に以下を返す
   - 再実行出力のハッシュ
   - 行数
   - 支持フラグ
   - 保留テストの対数損失要約
   - 実行環境メモ
   - 回避策があればその記録

## 4. この依頼で「してほしくないこと」

次のことはしないでください。

1. 予測子を追加・削除する
2. 閾値や支持判定規則を変える
3. 実行スクリプトを勝手に改善する
4. 正式参照ファイルを直接上書きする
5. 「うまくいくように」再設計する

この依頼は **再現実行タスク** であって、**再設計タスク** ではありませ
ん。

## 7. 実行者向けの手順説明

実行者は、次の順で進めれば十分です。

1. リポジトリを複製する
   または zip を展開する
2. 複製した場合は指定コミットに切り替える
3. `pip install -r requirements.txt`
4. `analysis/route_a_mixed_csp/external_outputs` を作る
5. 事前確認の試行
6. 事前確認の本実行
7. エンコーディング診断
8. 本実行前の試行
9. 本実行
10. 保留テスト集計
11. 出力ハッシュと要約を返送

詳しいコマンドは
`analysis/route_a_mixed_csp/mixed_csp_external_rerun_package.md`
にあります。
