# Exp43c 返信が来たらやること

このフォルダに外部実行者から返送が来たら、まずこの順で確認する。

## 1. 返送ファイルを分けて置く

実行者ごとに別フォルダを作る。

例:

```text
outside-rerun-1/
outside-rerun-2/
outside-rerun-3/
```

各フォルダに、返送された次のファイルを入れる。

1. `exp43c_primary_manifest_external.jsonl`
2. `exp43c_primary_results_external.jsonl`
3. `exp43c_primary_evaluation_external.json`
4. `実行環境メモ_テンプレート.md` を埋めたもの

## 2. 最低限そろっているか確認する

次の 4 つがあるかを見る。

1. manifest JSONL
2. results JSONL
3. evaluation JSON
4. 実行環境メモ

足りないものがあれば、その実行者には追加返送を依頼する。

## 3. ハッシュと行数を取る

各 `outside-rerun-*` フォルダ内で次を実行する。

```bash
shasum -a 256 exp43c_primary_manifest_external.jsonl
shasum -a 256 exp43c_primary_results_external.jsonl
shasum -a 256 exp43c_primary_evaluation_external.json
wc -l exp43c_primary_manifest_external.jsonl
wc -l exp43c_primary_results_external.jsonl
```

## 4. 最低限の結果を確認する

次を確認する。

1. manifest rows が `4000`
2. result rows が `4000`
3. evaluation JSON が生成されている
4. malformed / timeout pathology がないか
5. `fm_plus_n` が best raw baseline に勝っているか
6. q=3/4/5 の H1 方向が保たれているか

## 5. G7 レポートに写す

次のテンプレートを埋める。

```text
analysis/exp43_qcoloring/exp43c_g7_replication_report_template.md
```

最低限埋める場所:

1. package identity
2. outside-group environment note
3. returned artifacts
4. frozen-design compliance
5. core reproduction checks
6. quantitative summary
7. interpretation
8. one-line program update

## 6. 成功したらどうなるか

Exp43c で外部 rerun が成功すると、Mixed-CSP とは別の Route A ドメインで
outside-group support が立つ。

これは:

1. Route A の外部再現性が強くなる
2. SAT/NAE 以外の q-coloring 側でも handoff 可能性が確認される
3. G7 が単一ドメインではなく複数 Route A パッケージへ広がる

という意味がある。

ただし、これだけで non-CSP repair-flow や observational branches まで閉じ
るわけではない。

## 7. 失敗したらどうするか

1. informal rescue はしない
2. どの条件が落ちたかを記録する
3. 環境差分か、bundle 問題か、実行ミスかを切り分ける
4. 必要なら dedicated replication-failure note を切る
