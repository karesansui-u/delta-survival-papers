# Public PDF Set: Structural Persistence Theory

This folder contains the public-facing PDF set for the v3 Structural
Persistence Theory drafts.

Included:

- `01_structural_persistence_fixed_spec_layer_ja.pdf`
  - Public first draft.
  - Focus: basic accounting kernel and specification-fixed anchors.
- `02_structural_persistence_estimation_layer_ja.pdf`
  - Public second draft.
  - Focus: estimation-layer discipline, validation, support/non-support,
    silence, invalid execution, and failure ledger rules.

Publication note:

The first PDF should be read before the second. The first draft defines the
structural-maintenance coordinates; the second draft explains how estimated
domains should be validated without overclaiming support.

This folder may be published as a standalone public bundle. Do not make the
entire working repository public merely because this PDF set is public-ready;
other paths may contain non-public implementation experiments and evidence
details.
