Graph Spanning-Tree Persistence Freeze Manifest Draft
=====================================================

Status: draft; not frozen; not validation evidence.

Date opened: 2026-05-01

manifest_id: a31_graph_spanning_tree_persistence_v0

domain_id: graph_spanning_tree_persistence


1. Purpose
----------

This draft defines the fields that must be frozen before an outcome-bearing
validation run for graph spanning-tree persistence.

The package has two separate roles:

- exact accounting anchor: finite graph structure fixes
  \(\mathcal{T}(G_t)\), \(m(\mathcal{T}(G_t))=\tau(G_t)\), \(L_t\), and the
  collapse boundary \(\tau(G_t)=0\);
- prediction attempt: under oracle-excluded future edge deletion, test whether
  frozen spanning-tree persistence coordinates improve held-out future collapse
  prediction over a natural graph baseline.

The accounting anchor is not itself empirical support. Empirical support can be
claimed only from the frozen prediction task below.


2. Frozen Structural Mapping
----------------------------

Observation unit:

\[
  G_t=(U,E_t),\qquad E_t\subseteq E_{t-1}\subseteq E_0.
\]

The vertex set \(U\) is fixed. The first package is loss-only: damage means edge
deletion. Edge addition, repair, or weight changes require a separate
recovery-aware package.

Maintenance set:

\[
  \mathcal{T}(G_t)=
  \{T\subseteq E_t:T\text{ is a spanning tree on }U\}.
\]

Measure:

\[
  m(\mathcal{T}(G_t))=\tau(G_t),
\]

where \(\tau(G_t)\) is computed by the Matrix-Tree theorem or an equivalent
exact graph algorithm.

Loss coordinate:

\[
  L_t=-\log\frac{\tau(G_t)}{\tau(G_0)}
\]

for \(\tau(G_t)>0\). At the absorbing collapse boundary \(\tau(G_t)=0\), use the
extended-real convention \(L_t=+\infty\), and stop finite log updates.

Collapse:

\[
  Y_t=1\{\tau(G_t)=0\}=1\{G_t\text{ is disconnected}\}.
\]

Same-time collapse classification from the fully observed \(G_t\) is an oracle
endpoint and is not a prediction task.


3. Prediction Target
--------------------

Primary endpoint:

\[
  Y_{t,h}=1\{G_{t+s}\text{ becomes disconnected for some }1\le s\le h\}.
\]

This is future disconnection within horizon \(h\), under a pre-fixed edge
deletion process, predicted from the current graph \(G_t\) only.

The estimand is the conditional future-collapse probability

\[
  p_{t,h}=\Pr(Y_{t,h}=1\mid G_t,\text{frozen deletion process}),
\]

with labels generated by the fixed future-trajectory procedure in Section 5.

Secondary endpoints:

- truncated collapse time within horizon \(h\);
- retained future spanning-tree mass.

Retained future spanning-tree mass is secondary because it is close to the same
accounting coordinate under simple independent deletion processes. It must not
be the first primary endpoint in this package.


4. Data Surface
---------------

The first package uses synthetic finite, simple, undirected graphs. No
real-world network claim is made.

Candidate graph cells before final freeze:

- \(n\in\{24,32,40\}\);
- initial edge-count targets \(e_0\in\{2n,3n\}\), rounded only if required by
  graphical feasibility;
- edge connectivity / min-cut \(\kappa\in\{2,3\}\) at the initial graph level;
- connected initial graphs only, with \(\tau(G_0)>0\).

Candidate selection rule:

1. Generate candidate graphs by a pre-fixed deterministic generator and seed
   schedule.
2. Within each \((n,e_0,\kappa)\) cell, compute \(\log\tau(G_0)\).
3. Retain low, middle, and high \(\log\tau(G_0)\) strata so that same-size,
   same-density, same-min-cut graphs differ in spanning-tree mass.
4. Record every rejected graph count and rejection reason.

This selection uses base graph structure only. It is allowed because it is
part of the challenge design, but it must be frozen before any endpoint-bearing
future deletion labels are generated.

Graph-id split assignment must use a pre-fixed seed-random permutation within
each retained \((n,e_0,\kappa,\log\tau\text{-stratum})\) cell. Do not assign
train / validation / test by sorted \(\log\tau(G_0)\) rank.

If a retained cell has \(N_{\mathrm{cell}}\) graph ids, allocate
\(\lfloor0.2N_{\mathrm{cell}}\rfloor\) to validation,
\(\lfloor0.2N_{\mathrm{cell}}\rfloor\) to test, at least one graph id to each,
and assign the remainder to train. Cells with fewer than five graph ids are
invalid for the v0 package.

Spanning-tree counts in a support-bearing run must be computed by a frozen
exact or explicitly high-precision procedure. The default v0 procedure is the
Matrix-Tree theorem with an exact integer determinant, for example fraction-free
Bareiss elimination on the Laplacian cofactor. Floating determinant smoke
checks may be used for development only, not as the accounting method in a
support-bearing run.

The frozen generator must emit a spanning-tree count sanity artifact before any
support-bearing labels are used. Required cases include path graphs
\(\tau(P_n)=1\), cycle graphs \(\tau(C_n)=n\), and complete graphs
\(\tau(K_n)=n^{n-2}\) for a pre-fixed small range of \(n\). A failed sanity
artifact invalidates the run.

Prediction-row construction:

1. For each retained base graph \(G_0\), generate observed prefix states by
   applying a pre-fixed prefix deletion process.
2. Candidate prefix lengths before final freeze:
   \[
     p\in\{0,\lceil0.05e_0\rceil,\lceil0.10e_0\rceil\},
     \qquad e_0=|E_0|.
   \]
3. Retain only connected prefix states with \(\tau(G_t)>0\) as prediction rows.
4. Treat the prefix state \(G_t\) as observed at prediction time.
5. Generate future deletion labels from an independent future-deletion seed
   schedule, with the future trajectory count fixed before freeze.

This makes \(L_t\) non-degenerate while preserving the oracle boundary:
observed past damage is allowed, future damage is withheld.


5. Damage Process
-----------------

Primary damage process:

- uniform edge deletion without replacement;
- each future step removes one edge sampled uniformly from the current edge set;
- the process stops if the graph becomes disconnected or the horizon is reached.

Candidate horizons before final freeze:

- \(h\in\{\lceil 0.05e_t\rceil,\lceil 0.10e_t\rceil,\lceil 0.15e_t\rceil\}\),
  where \(e_t=|E_t|\) at the prediction row.

Future-label generation:

- for each prediction state \(G_t\), generate exactly \(K=64\) independent
  future deletion trajectories;
- each trajectory \(k\) yields a binary label
  \[
    y_{t,h,k}=1\{G_{t+s}^{(k)}\text{ becomes disconnected for some }1\le s\le h\};
  \]
- the state-level observed collapse fraction is
  \[
    \hat y_{t,h}=K^{-1}\sum_{k=1}^{K}y_{t,h,k}.
  \]

Training may use expanded trajectory rows with identical current-graph features.
Validation and test scoring must use the grouped binomial metric defined below,
not an unweighted raw trajectory-row average.

Before model fitting, the evaluator must audit that every
`labels_by_horizon.csv` count \(z\) equals the value recomputed from
`future_paths.csv`:

\[
  z_{t,h}=\sum_{k=1}^{K}1\{\text{first_disconnect_step}_{t,k}\le h\}.
\]

A label audit mismatch is an invalid-run condition, not support and not
no-support.

Final horizon selection must be made from calibration labels only and recorded
in the frozen manifest. It is a prevalence-only rule: model performance,
\(B1+SP_{\mathrm{bundle}}\) improvement, feature coefficients, and test labels
must not be used.
Compute graph-balanced calibration collapse prevalence for each candidate
horizon using the weighting rule in Section 9. Choose the smallest candidate
horizon whose calibration prevalence is nondegenerate:

- collapse fraction too low: less than 0.10;
- collapse fraction too high: greater than 0.90.

If no candidate horizon is nondegenerate in calibration, the package must be
marked redesign-required before freeze rather than evaluated as support.

After freeze, if the held-out test endpoint is degenerate despite passing the
calibration rule, report `no_support_endpoint_degeneracy` unless a documented
implementation or data-generation error invalidates the run.


6. Split Discipline
-------------------

Rows are grouped by base graph id. All future-deletion seeds for the same base
graph, including all prefix states derived from that graph, must remain in the
same split.

Required split:

- train: 60 percent of graph ids within each retained
  \((n,e_0,\kappa,\log\tau\text{-stratum})\) cell;
- validation: 20 percent of graph ids within each cell;
- test: 20 percent of graph ids within each cell.

No graph id may appear in more than one split. Hyperparameters, horizon choice,
feature transformations, and any missing-value rules are selected using train
and validation only. The test split is evaluated once.


7. Feature Sets
---------------

All features are computed from the current graph \(G_t\) and frozen deletion
process metadata available at prediction time.

Simple baseline \(B0\):

- \(|U|\);
- \(|E_t|\);
- edge density;
- deleted-edge count since \(G_0\);
- deleted-edge fraction since \(G_0\);
- mean degree;
- degree variance.

Natural graph baseline \(B1\):

- all \(B0\) features;
- minimum degree;
- edge connectivity / min-cut \(\kappa(G_t)\);
- bridge count;
- average shortest path length on connected \(G_t\);
- graph diameter on connected \(G_t\).

The natural graph baseline must not include:

- \(\tau(G_t)\);
- \(\log\tau(G_t)\);
- \(L_t\);
- spanning-tree deletion sensitivities;
- low-order cutset counts;
- cut-spectrum losses;
- exact future reliability or a Monte Carlo reliability estimate.

Primary SP model \(B1+SP_{\mathrm{bundle}}\):

- all \(B1\) features;
- \(\log\tau(G_t)\);
- \(L_t=-\log(\tau(G_t)/\tau(G_0))\) for \(\tau(G_t)>0\).

For manifest `a31_graph_spanning_tree_persistence_v0`, this two-feature
addition is the complete primary SP bundle. No leave-one-edge sensitivity,
cut-spectrum, low-order cutset, or other spanning-tree-derived feature may be
added to the v0 primary comparison after freeze.

The v0 primary support claim, if it passes, is for the spanning-tree
persistence bundle, not for \(L_t\) alone. The first primary package does not
include optional leave-one-edge summaries.

Required attribution ablations:

- \(B1+\log\tau(G_t)\);
- \(B1+L_t\);
- \(B1+\{\log\tau(G_t),L_t\}\).

Only an ablation that independently passes the same primary support rule may be
described as support for that single coordinate. Otherwise the support label is
restricted to the pre-frozen SP bundle.

Optional later SP extensions, not part of the v0 primary package:

- current-graph leave-one-edge spanning-tree loss summaries computed without
  future deletion realizations.

Any optional later SP extension requires a new manifest id or a separately
frozen successor package.

If optional leave-one-edge summaries are used, they must be computed from the
current graph using either:

- a pre-fixed uniform edge-risk distribution; or
- an all-edge leave-one-out rule.

Future realized deletion paths must not be used to compute any feature.

Wide graph baseline \(B2\), guardrail only unless explicitly promoted:

- all \(B1\) features;
- algebraic connectivity;
- spectral gap summaries;
- effective-resistance summaries;
- betweenness summaries;
- other pre-approved cheap graph invariants.

The wide baseline must not include the full Laplacian determinant,
\(\log\tau(G_t)\), exact future reliability, or a Monte Carlo estimate of the
target.


8. Model Class
--------------

Primary model class:

- L2-regularized logistic regression;
- during validation selection, numeric features standardized using train split
  mean and standard deviation;
- identical regularization grid for \(B0\), \(B1\), \(B1+SP_{\mathrm{bundle}}\),
  and \(B2\);
- regularization selected by graph-id grouped validation binomial log loss;
- final models refit on train + validation with the selected regularization,
  with the scaler also refit on train + validation;
- final test evaluation performed once after model selection and refit.

Training uses expanded trajectory rows. If \(I_g\) is the set of retained
prediction states for base graph \(g\), each trajectory row \((g,i,k)\) receives
sample weight

\[
  w_{g,i,k}=\frac{1}{N_{\mathrm{graphs}}\,|I_g|\,K}
\]

inside its split. This keeps each base graph equally weighted even when prefix
filtering leaves different numbers of connected prefix states.

Candidate regularization grid before final freeze:

\[
  C\in\{0.01,0.1,1,10\}.
\]

No model family may be changed after seeing test performance.


9. Metrics
----------

Primary metric:

- graph-id grouped binomial held-out test log loss for \(Y_{t,h}\).

For each prediction state \(i\) of graph \(g\), let \(z_{g,i}\) be the number of
collapsing future trajectories among the fixed \(K=64\) trajectories, and let
\(p_{g,i}\) be the model prediction clipped to \([\epsilon,1-\epsilon]\) with
\(\epsilon=10^{-15}\). The state loss is

\[
  \ell_{g,i}
  =
  -\frac{1}{K}
  \left[
    z_{g,i}\log p_{g,i}
    +(K-z_{g,i})\log(1-p_{g,i})
  \right].
\]

The graph loss is

\[
  \ell_g=|I_g|^{-1}\sum_{i\in I_g}\ell_{g,i}.
\]

The primary metric is

\[
  |G_{\mathrm{test}}|^{-1}\sum_{g\in G_{\mathrm{test}}}\ell_g.
\]

Do not use an unweighted row average as the primary metric.

Secondary metrics:

- Brier score;
- AUROC;
- calibration intercept / slope;
- collapse-time error for the secondary truncated-time endpoint;
- retained-mass error for the secondary retained-mass endpoint.

Secondary metrics should use the same graph-id grouping where applicable. If a
metric cannot be naturally grouped, report the grouping choice explicitly and do
not use that metric for support.


10. Support Rule
----------------

Primary support is true only if all of the following hold:

1. \(B1+SP_{\mathrm{bundle}}\) has lower graph-id grouped held-out test log
   loss than \(B1\).
2. Relative log-loss improvement over \(B1\) is at least 1 percent.
3. A paired bootstrap over graph ids with 2,000 frozen-seed replicates assigns
   positive improvement
   \(B1-B1{+}SP_{\mathrm{bundle}}>0\) in at least 90 percent of bootstrap
   replicates.
4. The improvement is not entirely driven by same-time oracle information:
   no future edge realization, final connectivity, exact future reliability, or
   Monte Carlo estimate of the target is present in the feature table.

Weak support:

- \(B1+SP_{\mathrm{bundle}}\) beats \(B0\) but fails one or more primary-support
  gates against \(B1\).

No-support:

- \(B1+SP_{\mathrm{bundle}}\) fails to improve over \(B1\) on primary graph-id
  grouped test log loss; or
- frozen test-stage endpoint degeneracy prevents meaningful evaluation; or
- any oracle-exclusion violation is found after feature audit.

Endpoint degeneracy handling:

- calibration-stage degeneracy before freeze: redesign-required, not
  no-support;
- frozen test-stage degeneracy after a valid freeze: if graph-balanced test
  collapse prevalence is below 0.02 or above 0.98, report
  `no_support_endpoint_degeneracy`;
- implementation or schema errors that invalidate the generated labels:
  invalid-run, not support and not no-support.

Wide-baseline guardrail:

- \(B2\) is diagnostic. Losing to \(B2\) does not by itself invalidate primary
  incremental support against \(B1\), but must be reported as evidence that the
  compressed SP coordinate is not the strongest available graph feature set.


11. Required Artifacts Before Freeze
------------------------------------

Before the manifest can be marked frozen, record:

- repository commit hash;
- generator script path;
- evaluator script path;
- manifest hash;
- graph generator seed schedule;
- graph-id split seed and split algorithm;
- prefix-deletion process hash;
- prefix-deletion seed schedule;
- future-deletion seed schedule;
- future trajectories per prediction state \(K=64\);
- spanning-tree count algorithm and precision rule;
- spanning-tree count sanity artifact;
- future-label count audit rule;
- graph-id grouped weighting rule;
- paired-bootstrap replicate count and seed;
- graph table schema;
- prediction-row table schema;
- feature table schema;
- final horizon;
- final graph cell list;
- final model hyperparameter grid;
- expected output files and checksums where available.

Smoke-test outputs are schema checks only and must not be treated as support
evidence.


12. Non-Claims
--------------

This package does not claim:

- a new graph invariant;
- real-world network robustness evidence;
- \(M\)-side validation;
- superiority over exact network reliability;
- same-time connectivity prediction from a fully observed graph;
- support for \(L_t\) alone unless the \(B1+L_t\) ablation independently passes
  the frozen support rule;
- support for A12 cut-spectrum reliability unless separately frozen;
- universal-law closure outside the finite graph setting.
