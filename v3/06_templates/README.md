Templates
=========

Use templates to keep new domains from changing the core theory by prose.

| Template | Use |
|---|---|
| `domain_profile_template.md` | register a new domain profile |
| `frozen_test_manifest_template.md` | freeze mapping, split, metric, baseline, and support rule |
| `m_profile_validation_manifest_template.md` | freeze optional M-component diagnostic signals and weak-axis independence gates |
| `outside_rerun_report_template.md` | report outside reruns |
| `no_support_record_template.md` | preserve failed or silent attempts |

For \(M\)-side work, \(M\) is first the effective maintenance surplus: the
support-side resource/slack usable for the maintenance problem. Use the
M-component diagnostic manifest only when this familiar resource side is
optionally operationalized through component readouts. The v3 template set does
not treat repair-policy choice as a core \(M\)-side validation target.
