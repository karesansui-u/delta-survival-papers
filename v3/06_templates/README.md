Templates
=========

Use templates to keep new domains from changing the core theory by prose.

| Template | Use |
|---|---|
| `domain_profile_template.md` | register a new domain profile |
| `frozen_test_manifest_template.md` | freeze mapping, split, metric, baseline, and support rule |
| `m_profile_validation_manifest_template.md` | freeze M-component signals and weak-axis independence gates |
| `intervention_effect_prereg_template.md` | freeze optional downstream intervention-effect studies |
| `outside_rerun_report_template.md` | report outside reruns |
| `no_support_record_template.md` | preserve failed or silent attempts |

For \(M\)-side work, \(M\) is first the effective amount of support-side
resource/slack usable for the maintenance problem. Use the M-profile manifest
only when this familiar resource side is operationalized through component
readouts. Use the intervention-effect preregistration only for a separate
downstream engineering study; it is not required for the core theory.
