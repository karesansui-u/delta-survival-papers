## 理論編の中心

理論編は、次の問いから始めています。

> 「持続する」「停止する」「崩壊する」を計算可能な問題として立てるには、
> 何を必ず明示しなければならないのか。

答えは、維持対象 `F`、必要構造 / 実現構造 `K`、維持可能領域 `V_K`、
損失または修復込み負担 `L/B`、有効支援 `M`、境界、時間範囲、
観測・変換器・証明書です。

G1 の必然性定理は、この文法が単なる便利な記法ではなく、明示された
保存条件と同値条件のもとで避けられないことを読む定理です。

## 各文書

- `構造持続理論.md`
  - 理論編。持続・停止・崩壊を計算可能な境界問題として立てるための
    必要文法、G1 必然性定理、G2/G3/G4、運用計算可能性、
    非主張境界を説明します。
- `PREPRINT_LEAN_ARTIFACT_ja.md`
  - Lean アーティファクト編。Lean が何を保証し、何を保証しないかを
    説明します。
- `M_補論.md`
  - M 側補論。名目資源 `R` と有効支援 `M` の分離、有限評価、
    支持 / 不支持 / 未決の境界を整理します。
- `L_補論.md`
  - L 側補論。Mixed-SAT/NAE-SAT によって、`L_mass` が raw count へ
    縮退しない有限 CSP 読みを整理します。

## 注意

この preprint 群は、世界の測定妥当性や経験的予測を Lean だけで保証するものでは
ありません。候補計算を、維持対象、必要構造、負担、有効支援、境界、根拠を持つ
読取りへ昇格させる条件を分けます。

不足する読取り資格条件は、未完成の約束ではなく、境界課題として記録します。
