# 持続通貨制度設計メモ

## 1. 基本発想

この制度は、資本主義を置き換えるものではない。資本主義の価格体系が見落としやすい、構造損失、有効資源不足、外部化された崩壊圧、将来の有効資源不足を、別の会計レイヤーとして価格体系へ戻す仕組みである。

短く言えば、これは次のような制度である。

```text
利益を出す主体だけでなく、
L を下げる主体、
有効資源 M を増やす主体、
必要有効資源量に対する不足 D を下げる主体、
外部へ押し出した崩壊圧を減らす主体へ、
型付き・期限付き・監査付きの報酬を出す。
```

ここでいう「持続通貨」は、何にでも使える汎用ポイントではない。むしろ、対象、期限、用途、測定根拠、外部性範囲が固定された、型付きの持続クレジットである。

## 2. なぜ必要か

通常の資本主義は、分散した意思決定と価格シグナルをうまく使える。一方で、次のものを過小評価しやすい。

- 保守
- 冗長性
- 予防
- 引き継ぎ
- ケア
- 余力
- 長期信頼
- 外部へ押し出された負担
- 境界に近づいているシステムの危険

その結果、次のような状態が起きる。

```text
利益は出ている
しかし L は増えている
有効資源 M は痩せている
必要有効資源量 M_required は増えている
外部 D を労働者、地域、環境、制度、将来世代へ押し出している
```

持続通貨制度の目的は、このズレを報酬体系へ戻すことである。

## 3. 構造持続理論の座標での読み

制度の基本座標は次の通り。

```text
F:
  何を維持するのか。

K:
  その F を担う構造。

L:
  構造損失。

M_nominal:
  名目上の資源。

M_eff:
  実際に使える損失調整後の有効資源。
  典型的には M_eff = M_nominal * exp(-L) と読む。

M_required:
  対象 F/K を指定期限で維持するための必要有効資源量。

D:
  有効資源不足、または崩壊圧。
  典型的には D = L + log(M_required / M_nominal) と読む。

External D:
  自分の外へ押し出した崩壊圧。
```

この制度は、「持続しているように見えるか」ではなく、どの F/K が、どの L、M、D、外部性のもとで維持されているかを見る。

## 4. 持続通貨の設計原則

### 4.1 汎用ポイントにしない

持続通貨を何にでも交換できるポイントにすると、すぐに Goodhart の法則に飲まれる。

そのため、通貨は型付きにする。

```text
医療余力クレジット
災害物流クレジット
送電網冗長性クレジット
重要 OSS 保守クレジット
地域ケア能力クレジット
AI 安全監査クレジット
水資源保全クレジット
```

異なる型のクレジットは、原則として相殺できない。相殺するには、別途 bridge certificate が必要である。

### 4.2 報酬は「良い状態」ではなく「認可された改善」に出す

単に良い状態に報酬を出すと、もともと強い主体が報酬を取り続ける。したがって、報酬は改善量に出す。

```text
L が下がった
M_eff が増えた
D が下がった
External D が下がった
境界下側から境界上側へ戻った
将来の必要有効資源量が下がった
```

ただし、改善量は事後に都合よく定義してはいけない。測定写像、対象 F/K、期限、proxy、監査範囲は事前に凍結する。

### 4.3 持続そのものを善にしない

持続には良い持続と悪い持続がある。

良い持続は、認可された F/K を、外部へ負担を押し出さず、変化可能性を残したまま維持することである。

悪い持続は、搾取構造、独占、ゾンビ企業、外部性の押し出し、本来変化すべき構造の延命である。

したがって制度は、「何でも持続させる」ものではなく、次を分けるためのものである。

```text
認可された持続
非認可な延命
外部化された持続
一時的な見かけの改善
```

## 5. 制度部品

### 5.1 持続準備金

国、自治体、国際機関、業界連合、財団などが、非常時に使える有効資源を蓄える。

これは単なる現金準備ではない。構造持続理論的には、有効資源として管理する。

```text
修復チーム
医療余力
予備設備
物流余力
保守人材
監査能力
計算資源
権限経路
緊急調達能力
```

準備金は、危機時に D が急上昇した主体へ一時的に貸し出される。

### 5.2 型付き持続クレジット

ある主体が他の系の L を下げたり、M_eff を増やしたり、External D を減らした場合、型付きクレジットを受け取る。

例:

```text
重要インフラの保守余力を増やした
地域医療の過負荷を下げた
災害時物流の回復経路を整えた
重要 OSS の保守体制を厚くした
労働者へ押し出していた疲弊 D を減らした
```

クレジットには次を必ず持たせる。

```text
対象 F/K
有効期限
使途
測定方法
監査者
外部性範囲
相殺可能な型
clawback 条件
```

### 5.3 持続ローン

一時的に D が高い主体へ、持続準備金または他の主体が有効資源を貸す。

貸すものは L そのものではない。貸すのは、次のいずれかである。

```text
L を下げる修復能力
M_eff を増やす有効資源
M_required を下げる再設計能力
外部 D を内部化する移行資源
```

返済は現金でもよいが、より 構造持続理論的には次で返す。

```text
将来の有効資源提供
持続準備金への拠出
外部 D の削減
修復能力の提供
監査済みの構造改善
```

### 5.4 崩壊圧課金

他者の L を増やす、他者の M_eff を削る、または External D を押し出す行為には課金する。

これは罰金というより、外部化された有効資源不足を価格へ戻す仕組みである。

```text
安く作って利益を出した
しかしサプライチェーンの L を増やした
地域医療の M_eff を削った
労働者の D を増やした
環境の M_required を増やした
```

この場合、利益だけではなく External D を含めて評価する。

### 5.5 境界回復ボーナス

有効資源境界の下側にいる主体を、上側へ戻す行為には追加報酬を与える。

```text
M_eff < M_required
から
M_eff > M_required
へ戻す
```

これは単なる改善量より重く評価する。なぜなら、境界をまたぐことは、持続主張の認可状態を変えるからである。

### 5.6 持続貢献台帳と税の再解釈

法人税、所得税、社会保険料、地方税などの一部は、単に「取られるお金」と見えやすい。どの系の持続に効いたのかが見えず、自分や自社が苦しいときに返ってくる実感も薄い。

持続通貨制度では、税の一部を次のように再解釈できる。

```text
税 = 社会全体の基礎持続を守る拠出
  + どの系へ貢献したかを記録する持続貢献台帳
  + 危機時に条件付きで引き出せる相互扶助権
```

ただし、払った税をそのまま自分へ返すだけにすると、税ではなく個人貯金になる。そのため、三層に分ける。

第一は、基礎公共層である。これは返還請求できない。医療、災害対応、司法、教育、最低生活、安全保障、基礎インフラなど、社会全体の最低限の持続を守るための層である。

第二は、型付き持続貢献層である。企業や個人がどの系の持続へ貢献したかを記録する。

```text
地域医療の M_eff を増やした
災害物流の M_eff を増やした
重要インフラの L を下げた
重要 OSS の保守余力を増やした
介護・ケア能力を増やした
環境回復のための External D を減らした
```

これは「返ってくるかもしれない社会的信用」として記録される。ただし、現金債権ではなく、型付き・条件付きの持続信用である。

第三は、相互扶助引出層である。企業や個人が一時的に境界下側へ落ちた場合、過去の貢献、現在の崩壊圧、再建可能性、外部性、悪い延命でないことを審査した上で、持続準備金や型付きクレジットから支援を受けられる。

引き出し条件の例:

```text
外部ショックで D が急上昇した
災害で M_eff が一時的に不足した
サプライチェーン崩壊で必要有効資源量が急増した
従業員ケア負担が急増した
地域インフラ障害で通常の有効資源が使えなくなった
支援により M_eff が境界上側へ戻る見込みがある
```

この仕組みでは、税は単なる損ではなく、社会全体の有効資源を厚くし、構造損失を下げるための拠出として見える。さらに、その一部は、危機時の優先支援、低利融資、修復能力の提供、または型付き持続クレジットとして返りうる。

ただし、この層にも強い guard が必要である。

```text
過去の貢献を理由に、悪い延命を許さない
わざと D を高く見せて支援を引き出させない
外部 D を増やしている主体には引き出し制限をかける
支援後に境界上側へ戻る見込みを要求する
支援の用途を限定する
再悪化や虚偽測定には clawback を入れる
```

この制度の狙いは、税を完全に個人口座化することではない。税の公共性を残したまま、どの系に貢献したかを可視化し、貢献した主体が一時的に苦しいときに、条件付きで社会的持続信用を引き出せるようにすることである。

### 5.7 見えにくい持続労働への循環

持続通貨制度の重要な効果は、通常の市場で低く評価されやすい持続労働へ、資金と信用を流せることである。

現実には、多くの人や団体が、さまざまな系の $L$ を下げたり、$M_{\mathrm{eff}}$ を増やしたり、将来の $D$ を下げている。

例:

```text
介護
子育て
地域の見守り
災害ボランティア
環境保全
重要 OSS の保守
メンタルヘルス支援
教育基盤の維持
インフラの地味な点検
コミュニティ運営
農地・水路・森林の維持
```

これらは社会の持続に効いているにもかかわらず、短期利益に直結しないため、無償、低賃金、不安定な活動として扱われやすい。

持続通貨制度では、税、拠出、崩壊圧課金、持続クレジットを通じて、こうした活動へ資金が循環する。

```text
企業や個人が税・拠出・崩壊圧課金を払う
↓
持続準備金 / 持続貢献台帳に入る
↓
各ドメインで L を下げる人・団体へ配分される
↓
地域、環境、医療、教育、OSS、ケアの M_eff が増える
↓
社会全体の D が下がる
↓
企業や個人も、危機時にその厚くなった系から支援を受けやすくなる
```

ここで大事なのは、活動者本人の持続も守ることである。他者の $L$ を下げる人は、自分の $L$ を上げやすい。

```text
介護者が他者の崩壊圧を下げながら、自分の疲弊を増やす
支援者が地域の D を下げながら、自分の生活余力を失う
OSS メンテナが社会の M_eff を増やしながら、自分の M_eff を削る
環境保全活動が社会の長期 D を下げながら、活動者の生活基盤を弱くする
```

したがって、持続通貨制度は、単に「良い活動に報酬を払う」だけでは足りない。持続労働の担い手自身の $L$ を下げ、$M_{\mathrm{eff}}$ を守る必要がある。

配分先は、単発報酬だけでなく、次のような形を含める。

```text
生活保障
社会保険
休息権
教育・訓練
道具・設備
移動費
メンタルケア
長期雇用
団体の基盤資金
危機時の優先支援
```

この層の目的は、善意を搾取することではない。市場が安く見積もっている「崩壊を防ぐ仕事」を、社会の有効資源を増やす正式な仕事として会計に載せることである。

ただし、報酬設計には注意が必要である。参加時間、写真映え、自己申告だけに報酬を出すと、すぐに Goodhart 化する。評価すべきなのは、測定可能な $L$ 低下、継続的な $M_{\mathrm{eff}}$ 増加、境界下側から上側への回復、External $D$ の削減である。

## 6. 報酬関数の一例

制度上の報酬は、たとえば次のように設計できる。

```text
Reward =
  a * ΔM_eff
  + b * (-ΔL)
  + c * (-ΔD_internal)
  + d * (-ΔD_external)
  + e * BoundaryRecoveryBonus
  + f * SustainedContributionCredit
  + g * SustainingLaborSupport
  - h * GoodhartDivergencePenalty
```

ここで `SustainedContributionCredit` は、税や拠出がどの系の有効資源を厚くし、どの構造損失を下げたかを型付きで記録した信用である。危機時には、別途審査を通じて支援優先権、低利融資、準備金利用、修復能力提供へ変換されうる。

`SustainingLaborSupport` は、他の系の $L$ を下げる人や団体自身の $L$ を下げ、$M_{\mathrm{eff}}$ を守るための支援である。これは単なる活動時間ポイントではなく、有効資源提供者の持続可能性を守る項として扱う。

係数 `a,b,c,d,e,f,g,h` は Lean や Structural Persistence Theory から自動的には出ない。これは社会的選択、政治、倫理、制度目的の問題である。

構造持続理論が与えるのは、係数そのものではなく、何を混ぜてはいけないか、どの主張がどの証明書に依存するか、どこに外部性が残っているかを分ける会計形式である。

## 7. Goodhart 対策

持続通貨制度が失敗する典型は、良いことポイント化である。

見るべきは、報酬スコアと実体の乖離である。

```text
報酬スコアは上がっている
しかし L も上がっている

報酬スコアは上がっている
しかし M_eff は下がっている

報酬スコアは上がっている
しかし External D が増えている

短期 D は下がっている
しかし長期 D は上がっている

対象 F は維持された
しかし周辺 F が壊れている
```

対策は次の通り。

```text
測定写像を事前に凍結する
事後的な F/K の変更を禁止する
proxy soundness を要求する
外部性台帳を別に持つ
短期改善と長期悪化を分ける
型の違うクレジットの相殺を制限する
境界回復後の再悪化には clawback を入れる
監査者と報酬受益者を分離する
税由来の持続信用を、無条件の引出権にしない
活動時間や自己申告だけを報酬対象にしない
持続労働の担い手本人の L/M_eff を監査対象に含める
```

Goodhart は完全には消えない。むしろ、人が指標へ最適化すること自体は制度の機能である。問題は、指標への最適化が本当の L、M、D、External D と乖離することである。

## 8. 持続通貨が扱うべきではないもの

次は、原則として持続通貨で安易に相殺してはいけない。

```text
人権侵害
不可逆な生態破壊
生命安全に関わる最低基準
制度的正統性の破壊
監査不能な proxy
被害者の同意なき外部性
```

これらは「高いクレジットを払えばよい」という対象ではない。相殺禁止領域として扱うか、非常に重い bridge certificate を要求する。

## 9. 最小実験案

いきなり国家制度にしない。最初は小さいドメインで試す。

候補:

```text
重要 OSS 保守
地域医療の待機余力
災害物流
SRE / インフラ保守
送電網の冗長性
介護・ケア能力
```

最小実験は次の形がよい。

```text
1. 対象 F/K を固定する
2. L, M_eff, M_required, D, External D を定義する
3. 測定 proxy を凍結する
4. 報酬対象を改善量に限定する
5. 税・拠出・寄付・支援を持続貢献台帳に記録する
6. 危機時の条件付き引出ルールを事前に固定する
7. 見えにくい持続労働への配分ルールを固定する
8. 持続労働の担い手本人の L/M_eff も監査する
9. 6〜12か月運用する
10. 報酬スコアと実体 L/M/D の乖離を監査する
11. 乖離が大きければ係数ではなく台帳設計を修正する
```

## 10. 成功条件

この制度が成功する条件は、次の三つである。

第一に、持続通貨を汎用ポイントにしないこと。対象、型、期限、使途、測定根拠を固定する。

第二に、報酬対象を状態の良さではなく、認可された改善に置くこと。特に、External D の削減を独立に評価する。

第三に、税や拠出を、単なる損ではなく、社会の有効資源を厚くする持続貢献として見える化すること。ただし、これは無条件の返還請求権ではなく、公共性を残した型付き・条件付きの相互扶助権である。

第四に、通常の市場で低く評価される持続労働へ資金を循環させること。特に、他者の $L$ を下げる人や団体自身の $L$ を下げ、$M_{\mathrm{eff}}$ を守る。

第五に、Goodhart 監査を制度の外側ではなく内側に置くこと。報酬スコアと L/M/D/External D の乖離を常に見る。

## 11. この制度の一文要約

持続通貨制度とは、資本主義の利益会計が見落とす構造損失、有効資源不足、必要有効資源量、外部化された崩壊圧を、型付き・期限付き・監査付きのクレジット、準備金、持続貢献台帳として扱い、認可された持続改善と見えにくい持続労働へ資源を流す制度である。

重要なのは、持続を無条件の善にしないことである。

```text
守るべき F/K を、
外部へ負担を押し出さず、
境界から遠ざけ、
将来の変化可能性を残しながら維持する。
```

この条件を満たすときだけ、持続は報酬されるべき対象になる。
